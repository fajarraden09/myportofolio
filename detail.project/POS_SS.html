Lihat Repository GitHub

Latar Belakang & Penjelasan Proyek

Aplikasi *Point of Sales* (POS) berbasis website ini dirancang khusus untuk memenuhi kebutuhan bisnis *Food & Beverage* di Sugriwa Subali Cafe.

Tantangan yang Dihadapi

Kafe membutuhkan sistem terpusat untuk melacak inventaris bahan baku, mempercepat antrean kasir, dan memantau pemasukan transaksi harian secara *real-time* yang dapat diakses dari mana saja.

Solusi Teknis
  • Merancang arsitektur database relasional (MySQL) yang solid untuk mencatat arus masuk keluar barang.
  • Mengembangkan RESTful API di sisi backend (Laravel) untuk kelancaran manajemen produk dan autentikasi berlapis.
  • Integrasi notifikasi laporan dengan API Fonnte.
Hasil & Dampak

Sistem ini berhasil di-deploy penuh ke *cloud* (Hostinger). Pendataan kasir dan pelaporan stok menjadi jauh lebih efisien, terstruktur, dan memperkecil kemungkinan *human error*.
