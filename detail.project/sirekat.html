Detail Proyek SI-REKAT

Sistem Informasi Keimigrasian (SI-REKAT) dibangun untuk memudahkan instansi dalam melakukan pengawasan terhadap Warga Negara Asing (WNA) secara terstruktur dan terotomatisasi.

Tantangan yang Dihadapi

Proses manual ekstraksi data dari dokumen PDF sangat memakan waktu. Selain itu, dibutuhkannya notifikasi secara langsung kepada petugas apabila terdapat indikasi *overstay*.

Solusi Teknis
  • Menggunakan Python dan teknologi AI (GPT) untuk membaca dan mengekstraksi data PDF secara otomatis.
  • Membuat sistem *Cron Job* pada Laravel yang dipadukan dengan API Fonnte untuk mengirim notifikasi peringatan otomatis 24/7 via WhatsApp.
Hasil & Dampak

Aplikasi ini sangat mengoptimalkan manajemen data skala besar dan menyediakan fitur Peta Kerawanan (GIS) interaktif untuk memantau pergerakan dengan cepat.
