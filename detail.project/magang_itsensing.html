Aplikasi Web GIS & Storymap

Magang Kemnaker Laravel, Leaflet, Cesium

Latar Belakang & Penjelasan Proyek

Proyek Aplikasi Web GIS & Storymap ini dikembangkan saat magang di Kemnaker. Tujuan utama aplikasi ini adalah untuk memberikan visualisasi data spasial secara interaktif, baik dalam bentuk peta 2 Dimensi (menggunakan Leaflet.js) maupun 3 Dimensi (menggunakan Cesium.js).

Tantangan yang Dihadapi

Tantangan utama adalah menggabungkan dua framework peta yang berbeda (Leaflet dan Cesium) dalam satu antarmuka agar pengguna bisa berpindah mode secara mulus tanpa *reload* halaman. Selain itu, terdapat masalah konfigurasi *build* pada server saat menggunakan Vite.

Solusi Teknis
  • Menggunakan Laravel sebagai backend untuk menyediakan data GeoJSON.
  • Mengatur manajemen *state* pada JavaScript untuk transisi Leaflet dan Cesium.
  • Melakukan optimasi `vite.config.js` agar *assets* 3D Cesium ter-*build* dengan benar di production server.
Hasil & Dampak

Aplikasi berhasil di-deploy ke server dan berjalan optimal. Pengguna dapat dengan mudah mencari lokasi (pencarian layer terintegrasi) dan melihat pemetaan data tenaga kerja secara visual yang akurat dan *real-time*.
